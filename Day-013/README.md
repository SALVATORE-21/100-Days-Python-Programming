# Day 13 - Debugging in Python

This lesson focuses on how to find and fix errors in Python programs.

## What you will learn

- How to use print statements to track the flow of a program
- How to handle errors with try and except
- How to understand error messages clearly
- How to test code with both valid and invalid input

## Example program

The file [main.py](main.py) shows a simple division program that demonstrates debugging and error handling.

### What the program does

- Takes two numbers from the user
- Converts them into integers
- Divides them
- Catches errors safely if something goes wrong

## Debugging methods used

1. Print statements
   - Help you see what the program is doing step by step.

2. Try and except blocks
   - Catch errors without stopping the whole program.

3. Reading error messages
   - Helps you understand what kind of problem occurred.

4. Testing with different inputs
   - Confirms whether the program works correctly.

## Common errors covered

- ValueError: when the user enters text instead of numbers
- ZeroDivisionError: when the second number is zero
- Unexpected errors: for any other unexpected issue

## Example output

When the user enters valid numbers, the program prints the result.

When the user enters invalid input, it shows a friendly error message instead of crashing.
